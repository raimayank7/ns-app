GST रिटार्न: सरकारि फरम, पर्टाल JSON आरो डिपार्टमेन्टनि Excel टुल

App-नि सिङाव GSTR-1, GSTR-3B, GSTR-2B आरो CMP-08 आ सरकारि फरम महरैनो खेवजायो: फरमनि मुं आरो नियम, नोंथांनि GSTIN आरो मुंफोर, समो आरो मोनफ्रोम टेबुल बिनि गावनि नम्बरनि सिङाव। रोखोमसे स्क्रिनफोरनिफ्राय नोंथां GST पर्टालनि थाखाय JSON फाइल डाउनल'ड खालामनो हायो, एबा NSBiz खौ डिपार्टमेन्टनि गावनि Excel अफलाइन टुलनि मोनसे कपि आबुं खालामनो होनो हायो। NSBiz आ पर्टालआव जेबो समाव लगिन खालामा: नोंथां नोंथांनि गावनि लगिनजों आपल'ड आरो फाइल खालामो।

स्टेप बाय स्टेप

  1. रिटार्न खेव। साइड मेनु › Statutory (GST and Tax) › GST: GSTR-1 Return, GSTR-3B Return, GSTR-2B Reconciliation एबा CMP-08 Statement। एबा Alt+G सिप आरो बेनि उनाव GA (GSTR-1), GB (GSTR-3B), GC (GSTR-2B) एबा CP (CMP-08)। रिटार्नआ App-नि सिङाव खेवजायो आरो नोंथां सेभ खालामनाय बिलफोरखौ फरायो।
  2. बिजिनेस आरो समो सायख। सिगाङाव: Business, बेनि उनाव Return for (One month एबा One quarter (QRMP)) आरो दान। GSTR-2B नि थाखाय, गिबियाव पर्टालनिफ्राय डाउनल'ड खालामनाय फाइलजों Open your GSTR-2B file (JSON or Excel) सिप; CMP-08 आ Quarter सोंयो।
  3. सरकारि फरम फराय। फरमखौ गिबियाव दिन्थियो, सरकारि फरमनि बादि, जोबनायाव भेरिफिकेसनजों। Print / PDF आरो Share PDF आ फरमखौ होयो।
  4. हिसाब नाय एबा सोलाय। बाकसोफोर आरो बिल बिल हिसाबआ फरमनि सिङाव थुबुरनानै थायो। Change the figures and see the working (GSTR-3B आरो CMP-08), See every table as the working (GSTR-1) एबा See every bill as the working (GSTR-2B) सिप। GSTR-3B आरो CMP-08 आव नोंथां जायखिजाया बाकसोनि सायाव लिरनो हायो आरो बेखौ दोननो Save this working सिप।
  5. GSTR-3B: पर्टालनि थाखाय JSON डाउनल'ड खालाम। हिसाब खेव आरो Download JSON for the GST portal सिप। फाइलनि मुंआव नोंथांनि GSTIN आरो दान थायो। पर्टालआव: Returns › GSTR-3B › Prepare Offline › Upload, बेनि उनाव फाइल खालामनायनि सिगाङाव अंकफोर नाय। बिजिनेसनि GSTIN खौ गिबियाव सेभ खालामनांगोन (My data › Businesses)।
  6. GSTR-1: JSON एबा GSTR-1 टेम्प्लेट। Files for the GST offline tool नि सिङाव: Download JSON for the GST portal (गिबियाव नायो; जेंनाफोरखौ गोरलै रावआव लिस्ट खालामो) एबा Returns Offline Tool नि थाखाय Fill the GSTR-1 template (Excel)।
  7. डिपार्टमेन्टनि Excel टुल आबुं खालाम (गिबि बार)। नोंथां लुबैनाय टुलनि Fill … बुथाम सिप (सिङाव लिस्ट)। गिबि बार मोनसे बाकसो The official … खेवजायो: बेनि लिंकजों gst.gov.in आव थां, टुल डाउनल'ड खालाम, बेनि उनाव Choose the downloaded file सिप। zip आ बेबादिनो मोजां; बेखौ खेवनो नांथाव नङा।
  8. आबुं खालामनाय कपिखौ Excel आव खेव। NSBiz आ नोंथांनि GSTIN, समो आरो "NSBiz" मुंजों मोनसे गोदान फाइल सेभ खालामो। बेखौ Excel आव खेव, म्याक्र' अन खालाम आरो टुलनि गावनि बुथामफोर बाहाय (GSTR-3B नि थाखाय: Validate, बेनि उनाव Generate JSON)। सरासनस्रा बादि पर्टालआव आपल'ड खालाम।
  9. उननि बार: मोनसे क्लिक। NSBiz आ डाउनल'ड खालामनाय टुलखौ बे डिभाइसआव दोनो आरो मोनफ्रोम बार बेखौ बाहायो, इन्टारनेट गैयैबो। gst.gov.in आ गोदान भारसन ओंखारोब्ला, बुथामनि सेरजाव Change template file सिप आरो गोदान डाउनल'डखौ सायख। Using … सारिआ मा फाइल दोननाय बेखौ दिन्थियो।

बिदिन्थिजों बुजि

October 2026, Sharma Hardware। App-नि सिङाव रमेशआ GSTR-3B Return खेवो, One month आरो October सायखो। फरमआ बिनि सेल्सजों टेबुल 3.1 आरो बिनि पारचेज बिलनि क्रेडिटजों टेबुल 4 दिन्थियो। बिहाया Change the figures and see the working खेवो, बिनि GSTR-2B आ दिन्थिनाय क्रेडिट लिरो, Save this working सिपो आरो बेनि उनाव Download JSON for the GST portal। फाइल 03ABCPS1234K1ZW_GSTR3B_102026.json आ Downloads आव थांयो; बिहाया बेखौ पर्टालआव Returns › GSTR-3B › Prepare Offline नि सिङाव आपल'ड खालामो आरो फाइल खालामनायनि सिगाङाव अंकफोर नायो।

बिनि एकाउन्टेन्टआ Excel युटिलिटि बेसि मोजां मोनो। गिबि बार, रमेशआ Fill the GST Offline Utility (Excel) सिपो, gst.gov.in निफ्राय GSTR3B Offline Utility डाउनल'ड खालामो आरो zip खौ सायखो। NSBiz आ "03ABCPS1234K1ZW_GSTR3B_OCT-2026 NSBiz.xlsm" सेभ खालामो; डाउनल'ड खालामनाय युटिलिटिखौ सोलाया। November आव मोनसे क्लिकनो जोबोद।

IMS टुलआ उल्टा खामानि मावो

IMS नि थाखाय नोंथां गिबियाव पर्टालनि IMS डेशबर्डआव रेकर्डफोर डाउनल'ड खालामो आरो बेफोरखौ बेनि गावनि बुथामजों IMS Offline Tool आव लोड खालामो। बेनि उनाव Suggest IMS actions (Excel) सिप आरो बे .xlsm फाइलखौ सायख। दा सिम No Action आव थानाय मोनफ्रोम सप्लायार इनभइस, डेबिट नोट आरो क्रेडिट नोटनि थाखाय, रोखोमसे सप्लायार आरो नम्बर नोंथांनि पारचेज बिलआव ₹1 नि सिङाव टेक्सजों थाब्ला NSBiz आ Accepted लिरो, आरो टेक्स गुबुन जाब्ला एबा बिलआ नोंथांनि बहिआव गैयाब्ला मोनसे रिमार्कजों Pending। NSBiz आ जेबो समाव Rejected सायखा: बेयो नोंथांनि थाखाय। गिबियावनो थि खालामनाय सारिफोरखौ बेबादिनो दोनो। मोनफ्रोम Pending खौ नाय, बेनि उनाव टुलनि गावनि बुथामजों आपल'ड खालाम।

गुदि फाइलखौ जेबो समाव सोलाया

NSBiz आ नोंथां डाउनल'ड खालामनाय टुलखौल' फरायो। बेयो नोंथांनि अंकफोरखौ मोनसे कपिआव लिरो, टुलनि म्याक्र', ड्रप-डाउन लिस्ट आरो बेनि गावनि फरमुलाफोर दोनो, आरो बे कपिखौ गोदान मुंआव सेभ खालामो। दोननाय टुलआ खामानि मावनो थादोब्ला (बिदिन्थि डिपार्टमेन्टआ बेनि लेआउट सोलायब्ला), NSBiz आ बेखौ बावगारो आरो गोदानखौ सोंयो।

कम्पिउटारआव NSBiz फल्डार

फल्डारआव अटो सेभ अन थाब्ला (कम्पिउटारआव Chrome एबा Edge, एबा NSBiz Windows प्रग्राम), NSBiz आ बेबो दोनो:

फल्डारबेनि सिङाव मा दं
NSBiz › GST Templatesनोंथां डाउनल'ड खालामनाय मोनफ्रोम टुलनि मोनसे कपि। बे कम्पिउटारनि मोनसे ब्राउजार, जायनि गावनि कपि मोसोनाय जाबाय, बेखौ बेनो मोनो।
NSBiz › GST Returns › नोंथांनि GSTIN › समोमोनफ्रोम आबुं खालामनाय रिटार्न, बिदिन्थि GST Returns › 03ABCPS1234K1ZW › Oct-2026। आबुं खालामनायनि उनाव मेसेजआ बुङो "Also saved in NSBiz › GST Returns"।

फल्डार गैयाब्लाबो, आबुं खालामनाय फाइलआ नोंथांनि Downloads आव सेभ जायो।

सरासनस्रा भुल आरो बेखौ माबोरै सुजुनाय

  • "Add the GSTIN of this business first"। JSON आरो मोनफ्रोम आबुं खालामनाय टुलनो नोंथांनि गावनि GSTIN नांगौ। बेखौ My data › Businesses आव दाजाब, बेनि उनाव बुथामखौ फिन सिप।
  • गाइडआव गोरोन्थि फाइल सायखनाय। बाकसोआव मुं लानाय टुलखौ सायख, gst.gov.in निफ्राय डाउनल'ड खालामनाय बादि (zip एबा बेनि सिङाव थानाय Excel फाइल)। मोनसे HSN सिट थानाय गोजाम GSTR-1 टेम्प्लेटखौ नाजा: गोदान Returns Offline Tool निफ्राय V2.2 बाहाय।
  • नायि फाइल खालामनाय। आबुं खालामनाय फाइल आरो JSON आ नोंथांनि हिसाब। फाइल खालामनायनि सिगाङाव मोनफ्रोम टेबुलखौ पर्टालनि गावनि अंक (GSTR-1 सारांश, GSTR-2B) जों नाय।
  • GSTR-3B नि बुथामफोर नागिरनाय। App-नि सिङाव बेफोरा थुबुरनाय हिसाबआव दं: फरमनि सिङाव Change the figures and see the working सिप।

सोंनाय-फिननाय

NSBiz आ आंनि रिटार्न फाइल खालामो नामा?

नङा। बेयो फरम, JSON आरो आबुं खालामनाय Excel टुल थियारि खालामो। नोंथां नोंथांनि गावनि लगिनजों GST पर्टालआव आपल'ड आरो फाइल खालामो।

मोनसे टुल आबुं खालामनो आंनो इन्टारनेट नांगौ नामा?

gst.gov.in निफ्राय टुल डाउनल'ड खालामनो गिबि बारल'। बेनि उनाव NSBiz आ बे डिभाइसआव दोननाय कपिखौ बाहायो।

डिपार्टमेन्टआ गोदान भारसन ओंखारोब्ला मा जायो?

बेखौ gst.gov.in निफ्राय डाउनल'ड खालाम आरो बुथामनि सेरजाव Change template file सिप। बेनि उनाव गोदानखौ दोनो।
