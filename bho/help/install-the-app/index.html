NSBiz कइसे इंस्टॉल करीं

इंस्टॉल कइला से App अपना अलग विंडो आ आइकन में आ जाला, दुकान से लिहल प्रोग्राम निहन। ई ओही App आ ओही डेटा ह जवन ब्राउज़र में बा: App के आपन फ़ाइल छोड़ के कुछ अउर डाउनलोड ना होला।

एक-एक स्टेप

  1. Chrome भा Edge में app.niveshsahayak.in खोलीं। कंप्यूटर (Windows, Mac, Linux) पर भा Android फ़ोन पर।
  2. ऐप इंस्टॉल करीं दबाईं। कंप्यूटर पर Install app बटन ऊपर टाइटल बार में बा। फ़ोन पर साइड मेन्यू खोलीं (ऊपर बाईं ओर मेन्यू बटन, भा टैब बार में More) आ Install NSBiz on this device दबाईं। एगो बॉक्स Install NSBiz on this device खुलेला आ बतावेला कि का मिली: आपन अलग विंडो आ आइकन, बिना इंटरनेट के खुलेला आ जल्दी चालू होला, आ अबहीं वाला एके डेटा।
  3. अबहीं इंस्टॉल करीं, भा देखावल स्टेप माने। अगर रउआ ब्राउज़र तुरंते इंस्टॉल कर सकेला, त बॉक्स में Install now बटन होला: ओकरा के दबाईं, फेर ब्राउज़र पूछे त Install। ना त बॉक्स ओह ब्राउज़र खातिर ठीक-ठीक स्टेप देखावेला जवन रउआ इस्तेमाल करत बानी (नीचे टेबल देखीं)। हो गइला पर संदेश आवेला Installed. Open it from your desktop or home screen.
  4. आइकन से खोलीं। Windows: Start मेन्यू भा डेस्कटॉप। Android: होम स्क्रीन भा ऐप ड्रॉअर। Mac: Applications भा Launchpad।
  5. पहिला बेर के सेटअप के जवाब दीं। इंस्टॉल कइल App पहिला बेर खुले पर पूछेला कि रउआ कवना तरह के बिज़नेस चलावेनी। देखीं पहिला बेर के सेटअप।

Install बॉक्स में देखाई देवे वाला स्टेप

ब्राउज़रस्टेप
कंप्यूटर पर Chromeएड्रेस बार के दाहिना छोर पर install आइकन पर क्लिक करीं, भा मेन्यू ⋮ › Cast, save and share › Install page as app खोलीं। Install दबाईं।
कंप्यूटर पर Edgeएड्रेस बार के दाहिना छोर पर App available आइकन पर क्लिक करीं, भा मेन्यू … › Apps › Install this site as an app खोलीं। Install दबाईं।
Android पर Chrome भा Edgeऊपर दाहिना ओर मेन्यू ⋮ दबाईं, फेर Add to home screen (भा Install app), फेर Install।
Samsung Internetनीचे मेन्यू ☰ दबाईं, फेर Add page to › Home screen।
Android पर Firefoxमेन्यू ⋮ दबाईं, फेर Install (भा Add to Home screen)।
iPhone आ iPad (Safari)Share बटन (तीर वाला चौकोर) दबाईं, नीचे स्क्रॉल करीं, Add to Home Screen दबाईं, फेर Add।

याद दिलावे वाला पट्टी

कवनो डिवाइस पर ब्राउज़र में App इस्तेमाल करे के तीसरा दिन से नीचे एगो पट्टी कहेले Install NSBiz on this device। Install बॉक्स खोले खातिर Install दबाईं, भा Not now: फेर ऊ 30 दिन ले ना आवेले। इंस्टॉल कइल App में भा Windows प्रोग्राम में ई कबो ना देखाई देला।

Windows प्रोग्राम

Windows कंप्यूटर पर Install बॉक्स Download NSBiz for Windows (मुफ़्त) भी देला: एगो आम Windows प्रोग्राम, जवना में रउआ डेटा के रोज के अपने से कॉपी आ ऑफ़िस नेटवर्क बा। देखीं NSBiz for Windows।

अपडेट

इंस्टॉल कइल App अपने से अपडेट होला: जब नया वर्ज़न आवेला, अगिला बेर इंटरनेट के साथे खोलला पर ऊ लोड हो जाला। नया डिज़ाइन के बाद आइकन बदले में एक दिन लाग सकेला। देखीं का नया बा आ अपडेट।

अनइंस्टॉल

Windows: App के विंडो में तीन-डॉट मेन्यू खोलीं › Uninstall। Android: आइकन के दबा के रखीं › Uninstall। अनइंस्टॉल कइला से विंडो आ आइकन हट जाला; सुरक्षित रहे खातिर पहिले बैकअप फ़ाइल सेव कर लीं।

आम गलती आ ओकर सुधार

  • ऐप इंस्टॉल करीं बटन नइखे। ई पहिले से इंस्टॉल बा (ओकर आइकन खोजीं), भा रउआ Windows प्रोग्राम में बानी। फ़ोन पर टाइटल बार में जगह ना होला: साइड मेन्यू खोलीं आ Install NSBiz on this device दबाईं। कवनो ऐप के भीतर के ब्राउज़र में (जइसे WhatsApp के भीतर वाला) पहिले एड्रेस के Chrome भा Safari में खोलीं।
  • Install app दबवनी आ खाली स्टेप देखाई दिहल। रउआ ब्राउज़र में एक टैप से इंस्टॉल नइखे। बॉक्स के स्टेप माने; कंप्यूटर वाला Firefox पर ओकरा जगह Chrome भा Edge इस्तेमाल करीं।
  • एगो ब्राउज़र से इंस्टॉल कइनी, डेटा दोसरा में टाइप कइल बा। Chrome आ Edge आपन-आपन अलग डेटा रखेला। ओही ब्राउज़र से इंस्टॉल करीं जहाँ रउआ डेटा पहिले से बा, भा बैकअप फ़ाइल से ले जाईं।
अबहीं आजमाईं: ई मुफ़्त बा आ लॉगिन के ज़रूरत नइखे।App खोलीं
