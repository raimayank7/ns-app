GST ریٹرن: سرکٲری فارم، پورٹل JSON تہٕ ڈیپارٹمنٹکۍ Excel ٹول

ایپس اندر چھِ GSTR-1، GSTR-3B، GSTR-2B تہٕ CMP-08 سرکٲری فارمہٕ پٲٹھۍ کھُلان: فارمُک ناو تہٕ قاعدٕ، تُہٕنٛد GSTIN تہٕ ناو، مُدت تہٕ پرٛتھ ٹیبل پنٕنِس نمبرس تَل۔ تِمنٕے اسکرینن پیٹھہٕ ہیٚکِو تۄہہ GST پورٹلہٕ خٲطرٕ JSON فایِل ڈاؤن لوڈ کٔرِتھ، یا NSBizس ڈیپارٹمنٹکِس پنٕنِس Excel آف لائن ٹولٕچ کاپی بَرنہٕ دِتھ۔ NSBiz چھُ نہٕ زانٛہہ پورٹلس منٛز لاگ اِن کران: تۄہہ چھِو پنٕنِس لاگ اِنس سٕتۍ اپ لوڈ تہٕ فائل کران۔

قدم بہٕ قدم

  1. ریٹرن کھولِو۔ سائیڈ مینو › Statutory (GST and Tax) › GST: GSTR-1 Return، GSTR-3B Return، GSTR-2B Reconciliation یا CMP-08 Statement۔ یا Alt+G تہٕ پتہٕ GA (GSTR-1)، GB (GSTR-3B)، GC (GSTR-2B) یا CP (CMP-08) دبٲوِو۔ ریٹرن چھُ ایپس اندر کھُلان تہٕ تُہٕنٛدۍ سیو کٔرِمتۍ بِل پران۔
  2. بزنس تہٕ مُدت ژٲرِو۔ پیٹھہٕ: Business، پتہٕ Return for (One month یا One quarter (QRMP)) تہٕ رٕت۔ GSTR-2B خٲطرٕ گۄڈٕ Open your GSTR-2B file (JSON or Excel) دبٲوِو تہٕ سۄ فایِل ژٲرِو یۄسہٕ تۄہہ پورٹلہٕ پیٹھہٕ ڈاؤن لوڈ کٔرِو؛ CMP-08 چھُ Quarter مَنگان۔
  3. سرکٲری فارم پٔرِو۔ فارم چھُ گۄڈٕ باسان، سرکٲری فارمہٕ ہِوۍ ترتیب، آخرس پیٹھ تصدیقس سٕتۍ۔ Print / PDF تہٕ Share PDF چھِ فارم دِوان۔
  4. حساب وُچھِو یا بدلٲوِو۔ باکس تہٕ بِل بِل حساب چھِ فارمس تَل ژھۄپِتھ۔ Change the figures and see the working (GSTR-3B تہٕ CMP-08)، See every table as the working (GSTR-1) یا See every bill as the working (GSTR-2B) دبٲوِو۔ GSTR-3B تہٕ CMP-08س منٛز ہیٚکِو کانٛہہ تہِ باکس بدلٲوِتھ تہٕ تھاونہٕ خٲطرٕ Save this working دبٲوِتھ۔
  5. GSTR-3B: پورٹلہٕ خٲطرٕ JSON ڈاؤن لوڈ کٔرِو۔ حساب کھولِو تہٕ Download JSON for the GST portal دبٲوِو۔ فایِلہِ ہُند ناو چھُ تُہٕنٛدِس GSTIN تہٕ رٕتس پیٹھ۔ پورٹلس پیٹھ: Returns › GSTR-3B › Prepare Offline › Upload، پتہٕ فائل کرنہٕ برونٛہہ فِگر چیک کٔرِو۔ بزنسُک GSTIN گژھِ گۄڈٕ سیو آسُن (My data › Businesses)۔
  6. GSTR-1: JSON یا GSTR-1 ٹیمپلیٹ۔ Files for the GST offline tool تَل: Download JSON for the GST portal (گۄڈٕ چیک گژھان؛ مسلہٕ سادٕ لفظن منٛز ہاونہٕ یِوان) یا Returns Offline Tool خٲطرٕ Fill the GSTR-1 template (Excel)۔
  7. ڈیپارٹمنٹُک Excel ٹول بٔرِو (گۄڈنِچ لٹہِ)۔ یَتھ ٹولس ضرورت چھےٚ، تَمیُک Fill … بٹن دبٲوِو (لِسٹ بۄنہٕ)۔ گۄڈنِچ لٹہِ چھُ اَکھ باکس The official … کھُلان: امیُک لِنک gst.gov.in پکِو، ٹول ڈاؤن لوڈ کٔرِو، پتہٕ Choose the downloaded file دبٲوِو۔ zip چھےٚ یِتھے ٹھیک؛ اَن زِپ کرنٕچ ضرورت چھےٚ نہٕ۔
  8. بٔرِمٕژ کاپی Excelس منٛز کھولِو۔ NSBiz چھُ اَکھ نٔو فایِل سیو کران، تُہٕنٛدِس GSTIN، مُدت تہٕ "NSBiz" سٕتۍ ناو۔ یہِ Excelس منٛز کھولِو، میکرو آن کٔرِو تہٕ ٹولکۍ پنٕنۍ بٹن ورتٲوِو (GSTR-3B خٲطرٕ: Validate، پتہٕ Generate JSON)۔ پورٹلس پیٹھ ہمیشہ ہِوۍ اپ لوڈ کٔرِو۔
  9. اگلہِ لٹہِ: اَکھ کلِک۔ NSBiz چھُ ڈاؤن لوڈ کٔرِمُت ٹول یَتھ ڈیوایِسس پیٹھ تھاوان تہٕ پرٛتھ لٹہِ ورتاوان، انٹرنیٹ وَرٲے تہِ۔ یلہِ gst.gov.in نوٚو ورژن جاری کرِ، بٹنس بٕرونٛہہ Change template file دبٲوِو تہٕ نوٚو ڈاؤن لوڈ ژٲرِو۔ لایِن Using … چھےٚ ہاوان کُس فایِل تھاونہٕ آمُت چھُ۔

حل کرنہٕ آمُت مثال

اکتوبر 2026، Sharma Hardware۔ ایپس اندر چھُ Ramesh GSTR-3B Return کھولان، One month تہٕ اکتوبر ژاران۔ فارم چھُ ٹیبل 3.1 تَمِس سٕنٛدِس سیلس سٕتۍ تہٕ ٹیبل 4 تَمِس سٕنٛدِس پرچیز بِلن ہٕنٛدِس کریڈٹس سٕتۍ ہاوان۔ سُہ چھُ Change the figures and see the working کھولان، سُہ کریڈٹ لیکھان یُس تَمیُک GSTR-2B ہاوان چھُ، Save this working تہٕ پتہٕ Download JSON for the GST portal دبٲوان۔ فایِل 03ABCPS1234K1ZW_GSTR3B_102026.json چھےٚ Downloads منٛز گژھان؛ سُہ چھُ یہِ پورٹلس پیٹھ Returns › GSTR-3B › Prepare Offline تَل اپ لوڈ کران تہٕ فائل کرنہٕ برونٛہہ فِگر چیک کران۔

تَمِس سٕنٛد اکاؤنٹینٹ چھُ Excel یوٹیلٹی پسند کران۔ گۄڈنِچ لٹہِ چھُ Ramesh Fill the GST Offline Utility (Excel) دبٲوان، gst.gov.in پیٹھہٕ GSTR3B Offline Utility ڈاؤن لوڈ کران تہٕ zip ژاران۔ NSBiz چھُ "03ABCPS1234K1ZW_GSTR3B_OCT-2026 NSBiz.xlsm" سیو کران؛ ڈاؤن لوڈ کٔرِمٕژ یوٹیلٹی چھےٚ نہٕ بدلان۔ نومبرس منٛز چھُ اَکھ کلِک کٲفی۔

IMS ٹول چھُ اُلٹہٕ پٲٹھۍ کام کران

IMS خٲطرٕ چھِو تۄہہ گۄڈٕ پورٹلکِس IMS ڈیش بورڈس پیٹھہٕ ریکارڈ ڈاؤن لوڈ کران تہٕ IMS Offline Toolس منٛز امِکِس پنٕنِس بٹنس سٕتۍ لوڈ کران۔ پتہٕ Suggest IMS actions (Excel) دبٲوِو تہٕ سۄ .xlsm فایِل ژٲرِو۔ پرٛتھ سپلائر انوائس، ڈیبٹ نوٹ تہٕ کریڈٹ نوٹ یُس وۄنۍ تام No Action پیٹھ چھُ، NSBiz چھُ Accepted لیکھان یلہِ تِیُے سپلائر تہٕ نمبر تُہٕنٛدِس پرچیز بِلن منٛز ₹1 اندر ٹیکسس سٕتۍ آسہِ، تہٕ Pending ریمارکس سٕتۍ یلہِ ٹیکس الگ آسہِ یا بِل تُہٕنٛدِس کھاتن منٛز نہٕ آسہِ۔ NSBiz چھُ نہٕ زانٛہہ Rejected ژاران: یہِ چھُ تُہٕنٛد فیصلہٕ۔ یِمن رۄوَن پیٹھ برونٛہہ فیصلہٕ گوٚمُت چھُ، تِم روزن یِتھۍ۔ پرٛتھ Pending چیک کٔرِو، پتہٕ ٹولکِس پنٕنِس بٹنس سٕتۍ اپ لوڈ کٔرِو۔

اصل فایِل چھےٚ نہٕ زانٛہہ بدلان

NSBiz چھُ صِرف سُہ ٹول پران یُس تۄہہ ڈاؤن لوڈ کوٚر۔ یہِ چھُ تُہٕنٛدۍ فِگر اَکِس کاپی منٛز لیکھان، ٹولکۍ میکرو، ڈراپ ڈاؤن لِسٹہٕ تہٕ امِکۍ پنٕنۍ فارمولا تھاوان، تہٕ سۄ کاپی نٔوِس ناوس سٕتۍ سیو کران۔ اگر کانٛہہ تھاونہٕ آمُت ٹول کام کرُن تراوِ (مثلاً ڈیپارٹمنٹن بدلوٚو امیُک لے آؤٹ)، NSBiz چھُ یہِ مٔشراوان تہٕ نوٚو مَنگان۔

سوال

کیاہ NSBiz چھُ میون ریٹرن فائل کران؟

نہٕ۔ یہِ چھُ فارم، JSON تہٕ بٔرِمُت Excel ٹول تیار کران۔ تۄہہ چھِو GST پورٹلس پیٹھ پنٕنِس لاگ اِنس سٕتۍ اپ لوڈ تہٕ فائل کران۔

کیاہ ٹول بَرنہٕ خٲطرٕ انٹرنیٹ ضروٗری چھُ؟

صِرف گۄڈنِچ لٹہِ، gst.gov.in پیٹھہٕ ٹول ڈاؤن لوڈ کرنہٕ خٲطرٕ۔ امہِ پتہٕ چھُ NSBiz یَتھ ڈیوایِسس پیٹھ تھاونہٕ آمٕژ کاپی ورتاوان۔

یلہِ ڈیپارٹمنٹ نوٚو ورژن جاری کرِ تیٚلہِ کیاہ گژھِ؟

یہِ gst.gov.in پیٹھہٕ ڈاؤن لوڈ کٔرِو تہٕ بٹنس بٕرونٛہہ Change template file دبٲوِو۔ امہِ پتہٕ چھُ نوٚو تھاونہٕ یِوان۔
