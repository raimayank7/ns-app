GST ਰਿਟਰਨਾਂ: ਸਰਕਾਰੀ ਫ਼ਾਰਮ, ਪੋਰਟਲ JSON ਅਤੇ ਵਿਭਾਗ ਦੇ Excel ਟੂਲ

ਐਪ ਦੇ ਅੰਦਰ GSTR-1, GSTR-3B, GSTR-2B ਅਤੇ CMP-08 ਖ਼ੁਦ ਸਰਕਾਰੀ ਫ਼ਾਰਮ ਵਾਂਗ ਖੁੱਲ੍ਹਦੇ ਹਨ: ਫ਼ਾਰਮ ਦਾ ਨਾਂ ਅਤੇ ਰੂਲ, ਤੁਹਾਡਾ GSTIN ਅਤੇ ਨਾਂ, ਸਮਾਂ ਅਤੇ ਹਰ ਟੇਬਲ ਆਪਣੇ ਨੰਬਰ ਹੇਠ। ਉਹਨਾਂ ਹੀ ਸਕ੍ਰੀਨਾਂ ਤੋਂ ਤੁਸੀਂ GST ਪੋਰਟਲ ਲਈ JSON ਫ਼ਾਈਲ ਡਾਊਨਲੋਡ ਕਰ ਸਕਦੇ ਹੋ, ਜਾਂ NSBiz ਤੋਂ ਵਿਭਾਗ ਦੇ ਆਪਣੇ Excel ਆਫ਼ਲਾਈਨ ਟੂਲ ਦੀ ਕਾਪੀ ਭਰਵਾ ਸਕਦੇ ਹੋ। NSBiz ਕਦੇ ਪੋਰਟਲ ’ਤੇ ਲੌਗਇਨ ਨਹੀਂ ਕਰਦਾ: ਤੁਸੀਂ ਆਪਣੇ ਲੌਗਇਨ ਨਾਲ ਅੱਪਲੋਡ ਅਤੇ ਫ਼ਾਈਲ ਕਰਦੇ ਹੋ।

ਕਦਮ-ਦਰ-ਕਦਮ

  1. ਰਿਟਰਨ ਖੋਲ੍ਹੋ। ਸਾਈਡ ਮੀਨੂ › Statutory (GST and Tax) › GST: GSTR-1 Return, GSTR-3B Return, GSTR-2B Reconciliation ਜਾਂ CMP-08 Statement। ਜਾਂ Alt+G ਦਬਾਓ ਅਤੇ ਫਿਰ GA (GSTR-1), GB (GSTR-3B), GC (GSTR-2B) ਜਾਂ CP (CMP-08)। ਰਿਟਰਨ ਐਪ ਦੇ ਅੰਦਰ ਖੁੱਲ੍ਹਦੀ ਹੈ ਅਤੇ ਤੁਹਾਡੇ ਸੇਵ ਕੀਤੇ ਬਿੱਲ ਪੜ੍ਹਦੀ ਹੈ।
  2. ਬਿਜ਼ਨਸ ਅਤੇ ਸਮਾਂ ਚੁਣੋ। ਉੱਪਰ: Business, ਫਿਰ Return for (One month ਜਾਂ One quarter (QRMP)) ਅਤੇ ਮਹੀਨਾ। GSTR-2B ਲਈ ਪਹਿਲਾਂ ਪੋਰਟਲ ਤੋਂ ਡਾਊਨਲੋਡ ਕੀਤੀ ਫ਼ਾਈਲ ਨਾਲ Open your GSTR-2B file (JSON or Excel) ਦਬਾਓ; CMP-08 Quarter ਪੁੱਛਦਾ ਹੈ।
  3. ਸਰਕਾਰੀ ਫ਼ਾਰਮ ਪੜ੍ਹੋ। ਫ਼ਾਰਮ ਸਭ ਤੋਂ ਪਹਿਲਾਂ ਦਿਖਦਾ ਹੈ, ਸਰਕਾਰੀ ਫ਼ਾਰਮ ਵਾਂਗ ਬਣਿਆ, ਅਖੀਰ ’ਤੇ ਵੈਰੀਫ਼ਿਕੇਸ਼ਨ ਨਾਲ। Print / PDF ਅਤੇ Share PDF ਫ਼ਾਰਮ ਦਿੰਦੇ ਹਨ।
  4. ਵਰਕਿੰਗ ਵੇਖੋ ਜਾਂ ਬਦਲੋ। ਬਾਕਸ ਅਤੇ ਬਿੱਲ-ਦਰ-ਬਿੱਲ ਵਰਕਿੰਗ ਫ਼ਾਰਮ ਦੇ ਹੇਠਾਂ ਮੋੜੇ ਹੋਏ ਹਨ। Change the figures and see the working (GSTR-3B ਅਤੇ CMP-08), See every table as the working (GSTR-1) ਜਾਂ See every bill as the working (GSTR-2B) ਦਬਾਓ। GSTR-3B ਅਤੇ CMP-08 ਵਿੱਚ ਤੁਸੀਂ ਕਿਸੇ ਵੀ ਬਾਕਸ ’ਤੇ ਲਿਖ ਕੇ ਰੱਖਣ ਲਈ Save this working ਦਬਾ ਸਕਦੇ ਹੋ।
  5. GSTR-3B: ਪੋਰਟਲ ਲਈ JSON ਡਾਊਨਲੋਡ ਕਰੋ। ਵਰਕਿੰਗ ਖੋਲ੍ਹ ਕੇ Download JSON for the GST portal ਦਬਾਓ। ਫ਼ਾਈਲ ਦਾ ਨਾਂ ਤੁਹਾਡੇ GSTIN ਅਤੇ ਮਹੀਨੇ ਨਾਲ ਹੁੰਦਾ ਹੈ। ਪੋਰਟਲ ’ਤੇ: Returns › GSTR-3B › Prepare Offline › Upload, ਫਿਰ ਫ਼ਾਈਲ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਅੰਕੜੇ ਚੈੱਕ ਕਰੋ। ਬਿਜ਼ਨਸ ਦਾ GSTIN ਪਹਿਲਾਂ ਸੇਵ ਹੋਣਾ ਚਾਹੀਦਾ ਹੈ (My data › Businesses)।
  6. GSTR-1: JSON ਜਾਂ GSTR-1 ਟੈਂਪਲੇਟ। Files for the GST offline tool ਹੇਠ: Download JSON for the GST portal (ਪਹਿਲਾਂ ਚੈੱਕ ਹੁੰਦੀ ਹੈ; ਮੁਸ਼ਕਲਾਂ ਸੌਖੇ ਸ਼ਬਦਾਂ ਵਿੱਚ ਦੱਸੀਆਂ ਜਾਂਦੀਆਂ ਹਨ) ਜਾਂ Returns Offline Tool ਲਈ Fill the GSTR-1 template (Excel)।
  7. ਵਿਭਾਗ ਦਾ Excel ਟੂਲ ਭਰੋ (ਪਹਿਲੀ ਵਾਰ)। ਜਿਹੜਾ ਟੂਲ ਚਾਹੀਦਾ ਹੈ ਉਸਦਾ Fill … ਬਟਨ ਦਬਾਓ (ਹੇਠਾਂ ਲਿਸਟ)। ਪਹਿਲੀ ਵਾਰ ਇੱਕ ਬਾਕਸ The official … ਖੁੱਲ੍ਹਦਾ ਹੈ: ਉਸਦੇ ਲਿੰਕ ਨਾਲ gst.gov.in ’ਤੇ ਜਾਓ, ਟੂਲ ਡਾਊਨਲੋਡ ਕਰੋ, ਫਿਰ Choose the downloaded file ਦਬਾਓ। zip ਜਿਵੇਂ ਹੈ ਠੀਕ ਹੈ; ਇਸਨੂੰ ਖੋਲ੍ਹਣ ਦੀ ਲੋੜ ਨਹੀਂ।
  8. ਭਰੀ ਕਾਪੀ Excel ਵਿੱਚ ਖੋਲ੍ਹੋ। NSBiz ਇੱਕ ਨਵੀਂ ਫ਼ਾਈਲ ਸੇਵ ਕਰਦਾ ਹੈ, ਤੁਹਾਡੇ GSTIN, ਸਮੇਂ ਅਤੇ "NSBiz" ਵਾਲੇ ਨਾਂ ਨਾਲ। ਇਸਨੂੰ Excel ਵਿੱਚ ਖੋਲ੍ਹੋ, ਮੈਕਰੋ ਚਾਲੂ ਕਰੋ ਅਤੇ ਟੂਲ ਦੇ ਆਪਣੇ ਬਟਨ ਵਰਤੋ (GSTR-3B ਲਈ: Validate, ਫਿਰ Generate JSON)। ਪੋਰਟਲ ’ਤੇ ਆਮ ਵਾਂਗ ਅੱਪਲੋਡ ਕਰੋ।
  9. ਅਗਲੀ ਵਾਰ: ਇੱਕ ਕਲਿੱਕ। NSBiz ਡਾਊਨਲੋਡ ਕੀਤਾ ਟੂਲ ਇਸ ਡਿਵਾਈਸ ’ਤੇ ਰੱਖਦਾ ਹੈ ਅਤੇ ਹਰ ਵਾਰ ਵਰਤਦਾ ਹੈ, ਇੰਟਰਨੈੱਟ ਤੋਂ ਬਿਨਾਂ ਵੀ। ਜਦੋਂ gst.gov.in ਨਵਾਂ ਵਰਜ਼ਨ ਲਿਆਵੇ, ਬਟਨ ਕੋਲ Change template file ਦਬਾ ਕੇ ਨਵਾਂ ਡਾਊਨਲੋਡ ਚੁਣੋ। ਲਾਈਨ Using … ਦੱਸਦੀ ਹੈ ਕਿ ਕਿਹੜੀ ਫ਼ਾਈਲ ਰੱਖੀ ਹੈ।

ਪੂਰੀ ਮਿਸਾਲ

ਅਕਤੂਬਰ 2026, Sharma Hardware। ਐਪ ਦੇ ਅੰਦਰ ਰਮੇਸ਼ GSTR-3B Return ਖੋਲ੍ਹਦਾ ਹੈ, One month ਅਤੇ ਅਕਤੂਬਰ ਚੁਣਦਾ ਹੈ। ਫ਼ਾਰਮ ਟੇਬਲ 3.1 ਵਿੱਚ ਉਸਦੀ ਵਿੱਕਰੀ ਅਤੇ ਟੇਬਲ 4 ਵਿੱਚ ਉਸਦੇ ਖ਼ਰੀਦ ਬਿੱਲਾਂ ਦਾ ਕ੍ਰੈਡਿਟ ਦਿਖਾਉਂਦਾ ਹੈ। ਉਹ Change the figures and see the working ਖੋਲ੍ਹਦਾ ਹੈ, ਉਸਦੀ GSTR-2B ਜੋ ਕ੍ਰੈਡਿਟ ਦਿਖਾਉਂਦੀ ਹੈ ਉਹ ਲਿਖਦਾ ਹੈ, Save this working ਅਤੇ ਫਿਰ Download JSON for the GST portal ਦਬਾਉਂਦਾ ਹੈ। ਫ਼ਾਈਲ 03ABCPS1234K1ZW_GSTR3B_102026.json Downloads ਵਿੱਚ ਜਾਂਦੀ ਹੈ; ਉਹ ਇਸਨੂੰ ਪੋਰਟਲ ’ਤੇ Returns › GSTR-3B › Prepare Offline ਹੇਠ ਅੱਪਲੋਡ ਕਰਦਾ ਹੈ ਅਤੇ ਫ਼ਾਈਲ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਅੰਕੜੇ ਚੈੱਕ ਕਰਦਾ ਹੈ।

ਉਸਦਾ ਅਕਾਊਂਟੈਂਟ Excel ਯੂਟਿਲਿਟੀ ਪਸੰਦ ਕਰਦਾ ਹੈ। ਪਹਿਲੀ ਵਾਰ ਰਮੇਸ਼ Fill the GST Offline Utility (Excel) ਦਬਾਉਂਦਾ ਹੈ, gst.gov.in ਤੋਂ GSTR3B Offline Utility ਡਾਊਨਲੋਡ ਕਰਦਾ ਹੈ ਅਤੇ zip ਚੁਣਦਾ ਹੈ। NSBiz "03ABCPS1234K1ZW_GSTR3B_OCT-2026 NSBiz.xlsm" ਸੇਵ ਕਰਦਾ ਹੈ; ਡਾਊਨਲੋਡ ਕੀਤੀ ਯੂਟਿਲਿਟੀ ਖ਼ੁਦ ਨਹੀਂ ਬਦਲਦੀ। ਨਵੰਬਰ ਵਿੱਚ ਇੱਕ ਕਲਿੱਕ ਕਾਫ਼ੀ ਹੈ।

IMS ਟੂਲ ਉਲਟੇ ਤਰੀਕੇ ਨਾਲ ਚੱਲਦਾ ਹੈ

IMS ਲਈ ਤੁਸੀਂ ਪਹਿਲਾਂ ਪੋਰਟਲ ਦੇ IMS ਡੈਸ਼ਬੋਰਡ ਤੋਂ ਰਿਕਾਰਡ ਡਾਊਨਲੋਡ ਕਰਦੇ ਹੋ ਅਤੇ IMS Offline Tool ਦੇ ਆਪਣੇ ਬਟਨ ਨਾਲ ਉਸ ਵਿੱਚ ਲੋਡ ਕਰਦੇ ਹੋ। ਫਿਰ Suggest IMS actions (Excel) ਦਬਾ ਕੇ ਉਹ .xlsm ਫ਼ਾਈਲ ਚੁਣੋ। ਹਰ ਸਪਲਾਇਰ ਇਨਵੌਇਸ, ਡੈਬਿਟ ਨੋਟ ਅਤੇ ਕ੍ਰੈਡਿਟ ਨੋਟ ਜੋ ਹਾਲੇ No Action ’ਤੇ ਹੈ, ਉਸ ਲਈ NSBiz Accepted ਲਿਖਦਾ ਹੈ ਜਦੋਂ ਉਹੀ ਸਪਲਾਇਰ ਅਤੇ ਨੰਬਰ ਤੁਹਾਡੇ ਖ਼ਰੀਦ ਬਿੱਲਾਂ ਵਿੱਚ ₹1 ਦੇ ਅੰਦਰ ਟੈਕਸ ਨਾਲ ਹੋਵੇ, ਅਤੇ ਟਿੱਪਣੀ ਨਾਲ Pending ਜਦੋਂ ਟੈਕਸ ਵੱਖਰਾ ਹੋਵੇ ਜਾਂ ਬਿੱਲ ਤੁਹਾਡੇ ਖਾਤਿਆਂ ਵਿੱਚ ਨਾ ਹੋਵੇ। NSBiz ਕਦੇ Rejected ਨਹੀਂ ਚੁਣਦਾ: ਉਹ ਫ਼ੈਸਲਾ ਤੁਹਾਡਾ ਹੈ। ਜਿਨ੍ਹਾਂ ਲਾਈਨਾਂ ਦਾ ਪਹਿਲਾਂ ਫ਼ੈਸਲਾ ਹੋ ਚੁੱਕਾ ਹੈ, ਉਹ ਜਿਵੇਂ ਹਨ ਰਹਿੰਦੀਆਂ ਹਨ। ਹਰ Pending ਚੈੱਕ ਕਰੋ, ਫਿਰ ਟੂਲ ਦੇ ਆਪਣੇ ਬਟਨ ਨਾਲ ਅੱਪਲੋਡ ਕਰੋ।

ਅਸਲ ਫ਼ਾਈਲ ਕਦੇ ਨਹੀਂ ਬਦਲਦੀ

NSBiz ਤੁਹਾਡਾ ਡਾਊਨਲੋਡ ਕੀਤਾ ਟੂਲ ਸਿਰਫ਼ ਪੜ੍ਹਦਾ ਹੈ। ਇਹ ਤੁਹਾਡੇ ਅੰਕੜੇ ਇੱਕ ਕਾਪੀ ਵਿੱਚ ਲਿਖਦਾ ਹੈ, ਟੂਲ ਦੇ ਮੈਕਰੋ, ਡਰਾਪ-ਡਾਊਨ ਲਿਸਟਾਂ ਅਤੇ ਉਸਦੇ ਆਪਣੇ ਫ਼ਾਰਮੂਲੇ ਰੱਖਦਾ ਹੈ, ਅਤੇ ਉਹ ਕਾਪੀ ਨਵੇਂ ਨਾਂ ਨਾਲ ਸੇਵ ਕਰਦਾ ਹੈ। ਜੇ ਰੱਖਿਆ ਟੂਲ ਕੰਮ ਕਰਨਾ ਬੰਦ ਕਰ ਦੇਵੇ (ਜਿਵੇਂ ਵਿਭਾਗ ਨੇ ਉਸਦੀ ਬਣਤਰ ਬਦਲ ਦਿੱਤੀ), ਤਾਂ NSBiz ਉਸਨੂੰ ਭੁੱਲ ਜਾਂਦਾ ਹੈ ਅਤੇ ਨਵਾਂ ਮੰਗਦਾ ਹੈ।

ਕੰਪਿਊਟਰ ’ਤੇ NSBiz ਫ਼ੋਲਡਰ

ਜਦੋਂ ਫ਼ੋਲਡਰ ਵਿੱਚ ਆਟੋ-ਸੇਵ ਚਾਲੂ ਹੋਵੇ (ਕੰਪਿਊਟਰ ’ਤੇ Chrome ਜਾਂ Edge, ਜਾਂ NSBiz ਦਾ Windows ਪ੍ਰੋਗਰਾਮ), NSBiz ਇਹ ਵੀ ਰੱਖਦਾ ਹੈ:

ਆਮ ਗਲਤੀਆਂ ਅਤੇ ਉਨ੍ਹਾਂ ਨੂੰ ਠੀਕ ਕਰਨ ਦਾ ਤਰੀਕਾ

  • "Add the GSTIN of this business first"। JSON ਅਤੇ ਹਰ ਭਰੇ ਟੂਲ ਨੂੰ ਤੁਹਾਡਾ ਆਪਣਾ GSTIN ਚਾਹੀਦਾ ਹੈ। ਇਹ My data › Businesses ਵਿੱਚ ਜੋੜੋ, ਫਿਰ ਬਟਨ ਦੁਬਾਰਾ ਦਬਾਓ।
  • ਗਾਈਡ ਵਿੱਚ ਗ਼ਲਤ ਫ਼ਾਈਲ ਚੁਣਨਾ। ਬਾਕਸ ਵਿੱਚ ਨਾਂ ਵਾਲਾ ਟੂਲ ਚੁਣੋ, ਜਿਵੇਂ gst.gov.in ਤੋਂ ਡਾਊਨਲੋਡ ਹੋਇਆ (zip ਜਾਂ ਉਸਦੇ ਅੰਦਰ ਵਾਲੀ Excel ਫ਼ਾਈਲ)। ਇੱਕ HSN ਸ਼ੀਟ ਵਾਲਾ ਪੁਰਾਣਾ GSTR-1 ਟੈਂਪਲੇਟ ਨਹੀਂ ਲਿਆ ਜਾਂਦਾ: ਤਾਜ਼ਾ Returns Offline Tool ਤੋਂ V2.2 ਵਰਤੋ।
  • ਚੈੱਕ ਕੀਤੇ ਬਿਨਾਂ ਫ਼ਾਈਲ ਕਰਨਾ। ਭਰੀ ਫ਼ਾਈਲ ਅਤੇ JSON ਤੁਹਾਡੀ ਵਰਕਿੰਗ ਹਨ। ਫ਼ਾਈਲ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਹਰ ਟੇਬਲ ਪੋਰਟਲ ਦੇ ਆਪਣੇ ਅੰਕੜਿਆਂ (GSTR-1 ਸਮਰੀ, GSTR-2B) ਨਾਲ ਮਿਲਾਓ।
  • GSTR-3B ਦੇ ਬਟਨ ਲੱਭਣਾ। ਐਪ ਦੇ ਅੰਦਰ ਇਹ ਮੋੜੀ ਹੋਈ ਵਰਕਿੰਗ ਵਿੱਚ ਹਨ: ਫ਼ਾਰਮ ਦੇ ਹੇਠਾਂ Change the figures and see the working ਦਬਾਓ।

ਸਵਾਲ-ਜਵਾਬ

ਕੀ NSBiz ਮੇਰੀ ਰਿਟਰਨ ਫ਼ਾਈਲ ਕਰਦਾ ਹੈ?

ਨਹੀਂ। ਇਹ ਫ਼ਾਰਮ, JSON ਅਤੇ ਭਰਿਆ Excel ਟੂਲ ਤਿਆਰ ਕਰਦਾ ਹੈ। ਤੁਸੀਂ GST ਪੋਰਟਲ ’ਤੇ ਆਪਣੇ ਲੌਗਇਨ ਨਾਲ ਅੱਪਲੋਡ ਅਤੇ ਫ਼ਾਈਲ ਕਰਦੇ ਹੋ।

ਕੀ ਟੂਲ ਭਰਨ ਲਈ ਇੰਟਰਨੈੱਟ ਚਾਹੀਦਾ ਹੈ?

ਸਿਰਫ਼ ਪਹਿਲੀ ਵਾਰ, gst.gov.in ਤੋਂ ਟੂਲ ਡਾਊਨਲੋਡ ਕਰਨ ਲਈ। ਉਸ ਤੋਂ ਬਾਅਦ NSBiz ਇਸ ਡਿਵਾਈਸ ’ਤੇ ਰੱਖੀ ਕਾਪੀ ਵਰਤਦਾ ਹੈ।

ਜਦੋਂ ਵਿਭਾਗ ਨਵਾਂ ਵਰਜ਼ਨ ਲਿਆਵੇ ਤਾਂ ਕੀ ਹੁੰਦਾ ਹੈ?

ਇਸਨੂੰ gst.gov.in ਤੋਂ ਡਾਊਨਲੋਡ ਕਰਕੇ ਬਟਨ ਕੋਲ Change template file ਦਬਾਓ। ਉਸ ਤੋਂ ਬਾਅਦ ਨਵਾਂ ਰੱਖਿਆ ਜਾਂਦਾ ਹੈ।

ਹੁਣੇ ਵਰਤ ਕੇ ਦੇਖੋ: ਇਹ ਮੁਫ਼ਤ ਹੈ ਅਤੇ ਲੌਗਇਨ ਦੀ ਲੋੜ ਨਹੀਂ।ਐਪ ਖੋਲ੍ਹੋ

ਹੋਰ ਮਦਦ

ਐਪ ਤੋਂ GST ਦਾ ਕੰਮਹਰ GST ਰਿਟਰਨ ਐਪ ਦੇ ਅੰਦਰ Statutory (GST and Tax) › GST ਤੋਂ ਖੁੱਲ੍ਹਦੀ ਹੈ ਅਤੇ ਤੁਹਾਡੇ ਸੇਵ ਕੀਤੇ ਬਿੱਲ ਅਤੇ ਖ਼ਰੀਦਾਂ ਪੜ੍ਹਦੀ ਹੈ।…GST TDS (GSTR-7) ਅਤੇ ITC ਵੰਡ (GSTR-6)ਦੋ ਖ਼ਾਸ GST ਰਜਿਸਟ੍ਰੇਸ਼ਨਾਂ ਲਈ ਦੋ ਸਕ੍ਰੀਨਾਂ। GST TDS deducted (GSTR-7) ਸਰਕਾਰੀ ਦਫ਼ਤਰਾਂ ਅਤੇ ਨੋਟੀਫ਼ਾਈਡ ਅਦਾਰਿਆਂ ਲਈ ਹੈ ਜੋ…GST ਸਟਾਕ ਫ਼ਾਰਮ: ITC-01, ITC-03, GSTR-10ਤਿੰਨ GST ਫ਼ਾਰਮਾਂ ਨੂੰ ਕਿਸੇ ਇੱਕ ਦਿਨ ਤੁਹਾਡੇ ਕੋਲ ਪਏ ਸਟਾਕ ਦੀ ਲਿਸਟ ਚਾਹੀਦੀ ਹੈ, ਹਰ ਆਈਟਮ ’ਤੇ ਸਪਲਾਇਰ ਦੇ ਬਿੱਲ ਅਤੇ GST ਕ੍ਰੈਡਿਟ ਨਾਲ।…ਜੌਬ ਵਰਕ ਅਤੇ ITC-04ਜੌਬ ਵਰਕਰ ਨੂੰ ਭੇਜਿਆ ਮਾਲ (ਕਟਿੰਗ, ਪਲੇਟਿੰਗ, ਸਿਲਾਈ…) ਤੁਹਾਡਾ ਹੀ ਸਟਾਕ ਰਹਿੰਦਾ ਹੈ। ਐਪ ਇਸਨੂੰ ਵਾਪਸ ਆਉਣ ਤੱਕ ਵੱਖਰੀ ਥਾਂ ਰੱਖਦਾ ਹੈ,…ਆਪਣਾ GSTR-1 ਬਣਾਓGSTR-1 ਤੁਹਾਡੀ ਵਿਕਰੀ ਦੀ ਮਹੀਨਾਵਾਰ (ਜਾਂ ਤਿਮਾਹੀ) ਰਿਟਰਨ ਹੈ। ਇਹ ਟੂਲ ਤੁਹਾਡੇ ਪਹਿਲਾਂ ਸੇਵ ਕੀਤੇ ਇਨਵੌਇਸ, ਕੈਸ਼ ਮੀਮੋ ਅਤੇ ਨੋਟ ਪੜ੍ਹ ਕੇ…
