GST ریٹرن: سرکاری فارم، پورٹل JSON اور محکمے کے Excel ٹولز

App کے اندر GSTR-1، GSTR-3B، GSTR-2B اور CMP-08 بالکل سرکاری فارم کی شکل میں کھلتے ہیں: فارم کا نام اور رول، آپ کا GSTIN اور نام، مدت اور ہر ٹیبل اپنے نمبر کے نیچے۔ انہی اسکرینوں سے آپ GST پورٹل کے لیے JSON فائل ڈاؤن لوڈ کر سکتے ہیں، یا NSBiz سے محکمے کے اپنے Excel آف لائن ٹول کی کاپی بھروا سکتے ہیں۔ NSBiz پورٹل میں کبھی لاگ اِن نہیں کرتا: اپ لوڈ اور فائل آپ اپنے لاگ اِن سے کرتے ہیں۔

قدم بہ قدم

  1. ریٹرن کھولیں۔ سائیڈ مینو › Statutory (GST and Tax) › GST: GSTR-1 Return، GSTR-3B Return، GSTR-2B Reconciliation یا CMP-08 Statement۔ یا Alt+G دبائیں اور پھر GA (GSTR-1)، GB (GSTR-3B)، GC (GSTR-2B) یا CP (CMP-08)۔ ریٹرن App کے اندر کھلتا ہے اور آپ کے سیو کیے بل پڑھتا ہے۔
  2. بزنس اور مدت چنیں۔ اوپر: Business، پھر Return for (One month یا One quarter (QRMP)) اور مہینہ۔ GSTR-2B کے لیے پہلے پورٹل سے ڈاؤن لوڈ کی فائل کے ساتھ Open your GSTR-2B file (JSON or Excel) دبائیں؛ CMP-08 Quarter مانگتا ہے۔
  3. سرکاری فارم پڑھیں۔ سب سے پہلے فارم دکھتا ہے، سرکاری فارم کی طرح بنا، آخر میں تصدیق کے ساتھ۔ Print / PDF اور Share PDF فارم دیتے ہیں۔
  4. ورکنگ دیکھیں یا بدلیں۔ باکس اور بل بہ بل ورکنگ فارم کے نیچے بند ہیں۔ Change the figures and see the working (GSTR-3B اور CMP-08)، See every table as the working (GSTR-1) یا See every bill as the working (GSTR-2B) دبائیں۔ GSTR-3B اور CMP-08 میں آپ کسی بھی باکس میں نیا لکھ کر Save this working دبا کر رکھ سکتے ہیں۔
  5. GSTR-3B: پورٹل کے لیے JSON ڈاؤن لوڈ کریں۔ ورکنگ کھولیں اور Download JSON for the GST portal دبائیں۔ فائل کا نام آپ کے GSTIN اور مہینے سے ہوتا ہے۔ پورٹل پر: Returns › GSTR-3B › Prepare Offline › Upload، پھر فائل کرنے سے پہلے اعداد چیک کریں۔ بزنس کا GSTIN پہلے سیو ہونا چاہیے (My data › Businesses)۔
  6. GSTR-1: JSON یا GSTR-1 ٹیمپلیٹ۔ Files for the GST offline tool کے نیچے: Download JSON for the GST portal (پہلے چیک ہوتا ہے؛ مسئلے آسان لفظوں میں لکھے جاتے ہیں) یا Returns Offline Tool کے لیے Fill the GSTR-1 template (Excel)۔
  7. محکمے کا Excel ٹول بھریں (پہلی بار)۔ جو ٹول چاہیے اس کا Fill … بٹن دبائیں (لسٹ نیچے)۔ پہلی بار ایک باکس The official … کھلتا ہے: اس کے لنک سے gst.gov.in پر جائیں، ٹول ڈاؤن لوڈ کریں، پھر Choose the downloaded file دبائیں۔ zip جیسی ہے ویسی ٹھیک ہے؛ کھولنے (unzip) کی ضرورت نہیں۔
  8. بھری ہوئی کاپی Excel میں کھولیں۔ NSBiz ایک نئی فائل سیو کرتا ہے، جس کے نام میں آپ کا GSTIN، مدت اور "NSBiz" ہوتا ہے۔ اسے Excel میں کھولیں، میکرو چالو کریں اور ٹول کے اپنے بٹن استعمال کریں (GSTR-3B کے لیے: Validate، پھر Generate JSON)۔ پورٹل پر ہمیشہ کی طرح اپ لوڈ کریں۔
  9. اگلی بار: ایک کلک۔ NSBiz ڈاؤن لوڈ کیا ٹول اسی ڈیوائس پر رکھتا ہے اور ہر بار استعمال کرتا ہے، انٹرنیٹ کے بغیر بھی۔ جب gst.gov.in نیا ورژن نکالے تو بٹن کے ساتھ Change template file دبائیں اور نیا ڈاؤن لوڈ چنیں۔ لائن Using … بتاتی ہے کون سی فائل رکھی گئی ہے۔

مثال سے سمجھیں

اکتوبر 2026، Sharma Hardware۔ App کے اندر Ramesh GSTR-3B Return کھولتا ہے، One month اور اکتوبر چنتا ہے۔ فارم ٹیبل 3.1 میں اس کی سیل اور ٹیبل 4 میں اس کے خرید بلوں کا کریڈٹ دکھاتا ہے۔ وہ Change the figures and see the working کھولتا ہے، اپنے GSTR-2B میں دکھا کریڈٹ لکھتا ہے، Save this working اور پھر Download JSON for the GST portal دباتا ہے۔ فائل 03ABCPS1234K1ZW_GSTR3B_102026.json Downloads میں جاتی ہے؛ وہ اسے پورٹل پر Returns › GSTR-3B › Prepare Offline میں اپ لوڈ کرتا ہے اور فائل کرنے سے پہلے اعداد چیک کرتا ہے۔

اس کا اکاؤنٹنٹ Excel یوٹیلٹی پسند کرتا ہے۔ پہلی بار Ramesh Fill the GST Offline Utility (Excel) دباتا ہے، gst.gov.in سے GSTR3B Offline Utility ڈاؤن لوڈ کرتا ہے اور zip چنتا ہے۔ NSBiz "03ABCPS1234K1ZW_GSTR3B_OCT-2026 NSBiz.xlsm" سیو کرتا ہے؛ ڈاؤن لوڈ کی گئی یوٹیلٹی خود نہیں بدلتی۔ نومبر میں ایک کلک کافی ہے۔

IMS ٹول الٹی طرح کام کرتا ہے

IMS کے لیے پہلے پورٹل کے IMS ڈیش بورڈ پر ریکارڈ ڈاؤن لوڈ کریں اور انہیں IMS Offline Tool میں اس کے اپنے بٹن سے لوڈ کریں۔ پھر Suggest IMS actions (Excel) دبائیں اور وہ .xlsm فائل چنیں۔ ہر سپلائر انوائس، ڈیبٹ نوٹ اور کریڈٹ نوٹ جو ابھی No Action پر ہے، اس کے لیے NSBiz Accepted لکھتا ہے جب وہی سپلائر اور نمبر آپ کے خرید بلوں میں ہو اور ٹیکس ₹1 کے اندر ہو، اور Pending ریمارک کے ساتھ جب ٹیکس الگ ہو یا بل آپ کے کھاتوں میں نہ ہو۔ NSBiz کبھی Rejected نہیں چنتا: یہ آپ کا فیصلہ ہے۔ جن لائنوں کا فیصلہ ہو چکا وہ ویسی ہی رہتی ہیں۔ ہر Pending والی چیک کریں، پھر ٹول کے اپنے بٹن سے اپ لوڈ کریں۔

اصل فائل کبھی نہیں بدلتی

NSBiz آپ کا ڈاؤن لوڈ کیا ٹول صرف پڑھتا ہے۔ یہ آپ کے اعداد ایک کاپی میں لکھتا ہے، ٹول کے میکرو، ڈراپ ڈاؤن لسٹیں اور اس کے اپنے فارمولے رکھتا ہے، اور وہ کاپی نئے نام سے سیو کرتا ہے۔ اگر رکھا گیا ٹول کام کرنا بند کر دے (مثلاً محکمے نے لے آؤٹ بدل دیا)، تو NSBiz اسے بھول کر نیا مانگتا ہے۔

کمپیوٹر پر NSBiz فولڈر

جب فولڈر میں آٹو سیو چالو ہو (کمپیوٹر پر Chrome یا Edge، یا NSBiz Windows پروگرام)، تو NSBiz یہ بھی رکھتا ہے:

فولڈراس میں کیا ہے
NSBiz › GST Templatesآپ کے ڈاؤن لوڈ کیے ہر ٹول کی کاپی۔ اس کمپیوٹر کا کوئی براؤزر جس کی اپنی کاپی صاف ہو گئی، اسے یہاں پا لیتا ہے۔
NSBiz › GST Returns › آپ کا GSTIN › مدتہر بھرا ہوا ریٹرن، مثلاً GST Returns › 03ABCPS1234K1ZW › Oct-2026۔ بھرنے کے بعد میسج کہتا ہے "Also saved in NSBiz › GST Returns"۔

فولڈر کے بغیر بھی بھری ہوئی فائل آپ کے Downloads میں سیو ہوتی ہے۔

عام غلطیاں اور انہیں کیسے ٹھیک کریں

  • "Add the GSTIN of this business first"۔ JSON اور ہر بھرے ٹول کو آپ کا اپنا GSTIN چاہیے۔ اسے My data › Businesses میں جوڑیں، پھر بٹن دوبارہ دبائیں۔
  • گائیڈ میں غلط فائل چننا۔ باکس میں جس ٹول کا نام ہے وہی چنیں، جیسا gst.gov.in سے ڈاؤن لوڈ ہوا (zip یا اس کے اندر کی Excel فائل)۔ ایک HSN شیٹ والا پرانا GSTR-1 ٹیمپلیٹ نہیں لیا جاتا: تازہ Returns Offline Tool کا V2.2 استعمال کریں۔
  • چیک کیے بغیر فائل کرنا۔ بھری فائل اور JSON آپ کی ورکنگ ہیں۔ فائل کرنے سے پہلے ہر ٹیبل پورٹل کے اپنے اعداد (GSTR-1 سمری، GSTR-2B) سے ملائیں۔
  • GSTR-3B کے بٹن ڈھونڈنا۔ App کے اندر وہ بند ورکنگ میں ہیں: فارم کے نیچے Change the figures and see the working دبائیں۔

سوالات

کیا NSBiz میرا ریٹرن فائل کرتا ہے؟

نہیں۔ یہ فارم، JSON اور بھرا Excel ٹول تیار کرتا ہے۔ GST پورٹل پر اپ لوڈ اور فائل آپ اپنے لاگ اِن سے کرتے ہیں۔

کیا ٹول بھرنے کے لیے انٹرنیٹ چاہیے؟

صرف پہلی بار، gst.gov.in سے ٹول ڈاؤن لوڈ کرنے کے لیے۔ اس کے بعد NSBiz اس ڈیوائس پر رکھی کاپی استعمال کرتا ہے۔

محکمہ نیا ورژن نکالے تو کیا ہوتا ہے؟

اسے gst.gov.in سے ڈاؤن لوڈ کریں اور بٹن کے ساتھ Change template file دبائیں۔ اس کے بعد نیا رکھا جاتا ہے۔
